# Internationalization

English ships first. The structure is ready for Simplified Chinese (`zh-cn`), Japanese (`ja`) and Korean (`ko`).

## How it is organised

- **Copy** lives in `src/i18n/<locale>/*.ts`, one module per page, aggregated by `src/i18n/<locale>/index.ts`. Pages never contain copy strings.
- **Long-form content** (insights, case studies) lives in `src/content/<collection>/<locale>/<slug>.md`. The entry id is `<locale>/<slug>`; pages filter by locale and strip the prefix for the URL.
- **Locale registry**: `src/i18n/config.ts` declares every locale (code, `<html lang>`, Open Graph locale, native name, text direction) and the list of `PUBLISHED_LOCALES`.
- **Routing**: `astro.config.mjs` `i18n` block. The default locale has no prefix; other locales mount at `/<code>/`.
- **Helpers**: `getDictionary(locale)` (deep-merges a partial translation over English so nothing renders empty), `localizePath(path, locale)`, `localeFromPath()`, `stripLocale()`.
- **SEO**: `Seo.astro` emits `hreflang` alternates for every published locale plus `x-default`; the sitemap integration receives the same list.

## Adding a locale (example: Japanese)

1. Copy `src/i18n/en/` to `src/i18n/ja/` and translate. Keep keys identical. Partial translations are fine: missing keys fall back to English.
2. Register it in `src/i18n/index.ts`:
   ```ts
   import ja from './ja/index.ts';
   const translations = { ja };
   ```
3. Add `'ja'` to `PUBLISHED_LOCALES` in `src/i18n/config.ts`.
4. Add `'ja'` to `i18n.locales` and `sitemap.i18n.locales` in `astro.config.mjs`.
5. Create the page tree for the locale. Astro renders one folder per locale, so either:
   - copy `src/pages/*` into `src/pages/ja/` (each page is a thin shell; the copy comes from the dictionary), or
   - enable Astro's fallback rewrite (`i18n.fallback: { ja: 'en' }`, `routing.fallbackType: 'rewrite'`) to serve English pages under `/ja/` until the folder exists.
6. Add content: `src/content/insights/ja/*.md`, `src/content/case-studies/ja/*.md`.
7. Fonts: Latin subsets are self-hosted. For CJK, add a local or Google provider entry in `astro.config.mjs` `fonts` with a `unicodeRange`, or rely on system fonts via `fallbacks` (recommended for performance).
8. Open Graph images: `src/pages/og/[...key].png.ts` reads the English dictionary; extend `getStaticPaths` to loop over locales when CJK fonts are added to the satori font list.

## Writing guidance for translators

- Keep `[PLACEHOLDER: ...]` tokens untranslated; they are replaced before launch.
- Technical terms (SerDes, PHY, PLL, ADPLL, UCIe, DFI, PVT) stay in English.
- Numbers and units use the SI forms already in the English copy.
